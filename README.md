# Controles Sisplan V2

## Novidades
- Botão **ALTERAR** dentro de cada Relatório/Tela.
- Alteração de nome, form, categoria, tags, observações, FR3 e print.
- Nova aba **Controle de Horas**.
- Dois valores configuráveis: hora normal e adicional de viagem por hora.
- Flag **Viagem**. Cálculo: horas × (hora normal + adicional viagem), quando marcado.
- Lançamento por data, cliente e total de horas.
- Faturamento filtrado por mês/ano, cliente, cidade e viagem.
- Resumo de faturamento por cidade.
- Nova aba **Clientes Sisplan**, com clientes ativos extraídos de `CLIENTES SISPLAN.csv`.
- Backup V2 inclui relatórios, horas e parâmetros.

## Publicação
O Netlify está conectado ao GitHub. Alterações enviadas à branch `main` são publicadas automaticamente.
